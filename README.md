# talos-theme

Front-end de Talos 2.0. Todo el CSS/JS es propio:

- `assets/css/talos-shell.css` — shell (sidebar, topbar) y componentes base.
- `assets/js/talos-app.js` — comportamiento compartido (ordenar tablas, etc.).
- Iconos: sprite SVG propio en `header.php`. Tipografía: Poppins (Google Fonts).

No depende de Approx ni de Bootstrap. La lógica de negocio vive en el plugin `talos-core`.
